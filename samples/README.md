# Samples

Danh sach game mau de demo GoPortal game flow:

- `samples/demo-html-game`: demo tap score co ban.
- `samples/single-player-score`: game 1 nguoi choi, tinh diem theo session + share score.
- `samples/multiplayer-tank-room`: game multiplayer room realtime, co demo sync state + auto resync khi lech `state_version`.
- `samples/tank-battle-complete`: game ban xe tang hoan chinh, cover full SDK v2 (room + state + full share flow + share status events).

Neu upload len GoPortal, can dam bao `index.html` nam o root cua file zip.
